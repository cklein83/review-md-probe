# Review instructions

Dies ist eine Testdatei, um zu pruefen, ob die native Claude Code Review
GitHub App dieses Dokument tatsaechlich liest und anwendet.

## Regel ZZZ-9: Keine TODO-Kommentare im Code

**Gewuenschtes Verhalten:** Neuer Code darf keinen Kommentar enthalten, der
woertlich die Zeichenkette "TODO-PROBE-MARKER-9f3a" enthaelt.

**Detection-Kriterium:** Taucht "TODO-PROBE-MARKER-9f3a" irgendwo im Diff auf,
ist das ein Verstoss gegen Regel ZZZ-9.

Wenn du beim Review einen Verstoss gegen eine Regel in diesem Dokument findest,
beginne den entsprechenden Abschnitt woertlich mit "Regel: ZZZ-9".
